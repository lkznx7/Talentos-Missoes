# Proteção de Dados

- Minimização de PII em respostas e logs.
- Retenção de dados a definir (pendente).
- Soft delete para preservar auditoria (proposto).
- Exportação/exclusão de dados (LGPD) pendente de avaliação jurídica.
- Criptografia em repouso depende da infraestrutura/BaaS escolhido.
- Backups protegidos e acesso restrito.
- Consentimento e bases legais a definir com produto/jurídico.
