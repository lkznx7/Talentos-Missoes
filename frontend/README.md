# Frontend

Next.js 16.4, React 19.3, TypeScript, App Router e npm. Sem integrações com backend ou telas de produto. O lockfile ainda precisa ser gerado e versionado quando o acesso ao registry npm estiver disponível.

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

Requer Node.js 20.9 ou superior. Porta padrão 3000. `NEXT_PUBLIC_API_BASE_URL` é apenas referência estrutural e ainda não consumida.
